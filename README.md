### 02.10.2026 — Розробка Юнітів 1–3: Рух, Оточення та Система здоров'я

#### Юніт 1: Персонаж і базовий рух
**Що зроблено:**
- Налаштовано проєкт Unity 2D та імпортовано арт-асети.
- Створено префаб персонажа `PlayerCharacter` із компонентами `Sprite Renderer`, `Rigidbody 2D` та `Box Collider 2D`.
- Створено та налаштовано Input Action Assets для керування рухом через клавіатуру (WASD / стрілки).
- Написано базовий скрипт `PlayerController.cs` для зчитування вводу гравця та оновлення позиції об'єкта.

**Що не вийшло або забрало найбільше часу:**
- Налаштування нової системи вводу Unity (New Input System) та правильна підв'язка `InputAction` у коді.

---

#### Юніт 2: Оточення та фізика
**Що зроблено:**
- Налаштовано тайлсет (Tilemap) для побудови ігрового рівня (земля, паркани, декорації).
- Додано колайдери на об'єкти оточення за допомогою `Tilemap Collider 2D` та `Composite Collider 2D`.
- Оптимізовано рух гравця через використання `rigidbody2d.MovePosition()` у `FixedUpdate()`, щоб уникнути проходження крізь стіни та тремтіння камери.

**Що не вийшло або забрало найбільше часу:**
- Підганяння колайдерів ящиків та точок зіткнення персонажа, щоб гравець не застрягав на кутах об'єктів.

---

#### Юніт 3: Система здоров'я
**Що зроблено:**
- Додано параметри здоров'я (`maxHealth`, `currentHealth`) та швидкості (`speed`) у скрипт `PlayerController.cs`.
- Створено властивість `health` (лише для читання) та функцію `ChangeHealth()` із використанням `Mathf.Clamp` для обмеження значень здоров'я в межах [0, maxHealth].
- Реалізовано механіку невразливості гравця після отримання шкоди (`timeInvincible`, `isInvincible`, `damageCooldown`).
- Створено тригерний об'єкт аптечки зі скриптом `HealthCollectible.cs`, який додає 1 HP і зникає лише за умови, що здоров'я гравця не максимальне.
- Реалізовано зони шкоди зі скриптом `DamageZone.cs` та функцією `OnTriggerStay2D`, а також встановлено `Sleeping Mode = Never Sleep` у `Rigidbody 2D` гравця.

**Що не вийшло або забрало найбільше часу:**
- Виправлення помилки компіляції CS0122 через приватний доступ до `currentHealth`. Проблему вирішено створенням властивості `public int health { get { return currentHealth; } }`.

**Що зрозумів про тригери, public і private:**
- Звичайні колайдери блокують рух, а тригери (`Is Trigger`) пропускають об'єкт і генерують події в коді (`OnTriggerEnter2D`, `OnTriggerStay2D`).
- Модифікатор `public` дозволяє налаштовувати поля в Inspector та звертатися до них з інших скриптів, а властивість із блоком `get` захищає значення від несанкціонованого перезапису іншими класами.

**Яке значення Time Invincible обрав і для якого гравця:**
- Встановив значення `2.0` секунди. Це дає казуальному гравцю достатньо часу, щоб зреагувати та вийти з зони шкоди, роблячи ігровий процес справедливим.

**Що робитиму далі:**
- Переходжу до Юніту 4 для розробки ворогів та їхньої поведінки.
